8. 🔍 DIAGNOSTIC DES ERREURS POSSIBLES
═══════════════════════════════════════════════════════════════════

Si vous voyez dans la console:

"42501" ou "row-level security policy"
→ Les politiques RLS bloquent
→ Exécutez fix-rls-policies.sql

"23503" ou "foreign key constraint"
→ user_id invalide (ancien ID)
→ Videz le cache + reconnectez-vous

"JWT expired" ou "invalid claim"
→ Token expiré
→ Déconnectez-vous et reconnectez-vous

"CORS" ou "Access-Control-Allow-Origin"
→ Configuration CORS
→ Ajoutez http://localhost:5173 dans Supabase Settings → API
