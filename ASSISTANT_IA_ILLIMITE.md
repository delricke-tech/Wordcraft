## 🆘 QUESTIONS FRÉQUENTES

### Combien de documents puis-je importer ?
**AUTANT QUE VOUS VOULEZ !** Il n'y a plus de limite.

### Ça va être lent avec 100 documents ?
- **Extraction** : Oui, quelques minutes (normal)
- **Réponses IA** : Légèrement plus lentes, mais fonctionnelles
- **Astuce** : Importez tout d'un coup, puis utilisez pendant des heures

### L'IA va se perdre avec trop de documents ?
**Non !** L'IA GPT-4o-mini est conçue pour gérer de grands contextes. Elle va :
- Identifier les documents pertinents pour votre question
- Synthétiser les informations importantes
- Citer ses sources

### Que se passe-t-il si j'atteins les limites de OpenAI ?
- OpenAI GPT-4o-mini a une limite de ~128k tokens de contexte
- Si vous dépassez, l'IA vous le dira
- Solution : Supprimez les documents les moins pertinents pour votre question actuelle
