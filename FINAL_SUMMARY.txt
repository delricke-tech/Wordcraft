✅ RÉCAPITULATIF TECHNIQUE
═══════════════════════════════════════════════════════════════════

FLUX COMPLET D'UN UPLOAD:

1. Génération safePath
   generateUniqueFileName("Mon Été.pdf")
   → "1735...-mon-ete.pdf"

2. Upload Storage
   supabase.storage.upload(safePath, file)
   → uploadData.path = "1735...-mon-ete.pdf"

3. Insertion BDD
   {
     name: "Mon Été.pdf",           ← Nom original
     storage_path: uploadData.path, ← Path nettoyé
     user_id: user.id               ← User actuel
   }
   → successfulUploads++

4. Trigger SQL
   Normalise storage_path si nécessaire

5. Fetch avec Filtrage
   .eq('user_id', user.id)
   → Récupère uniquement VOS documents

6. Affichage Grille
   Documents affichés avec nom original
