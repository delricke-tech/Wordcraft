# ✅ GUIDE EXPRESS - MENU ACTIONS RAPIDES

## 🚀 COMMENT UTILISER L'INTERCONNEXION

### 1️⃣ MENU FLOTTANT (Bouton ➕)

**Position** : Coin bas-droite de l'écran
**Toujours visible** : Sur toutes les pages

#### Actions disponibles :
```
┌────────────────────────────────┐
│  🎥  Session vidéo             │
│  💬  Message                   │
│  👥  Groupe                    │
│  📚  Fiche                     │
│  📝  Quiz                      │
│  📄  Document                  │
│  ✨  Assistant IA              │
└────────────────────────────────┘
```

#### Comment utiliser :
1. Cliquez sur le bouton ➕ vert (bas-droite)
2. Menu s'ouvre avec animation
3. Cliquez sur l'action souhaitée
4. Vous êtes redirigé instantanément

---

### 2️⃣ ACTIONS CONTEXTUELLES

**Position** : En haut de chaque volet
**Adapté au contexte** : Actions pertinentes

#### Par volet :

**💬 Dans Messages**
- [🎥 Session vidéo] → Lancer session avec le contact
- [👥 Créer groupe] → Groupe avec ce contact
- [📤 Partager fiche] → Partager une fiche

**👥 Dans Groupes**
- [🎥 Lancer session] → Session pour le groupe
- [💬 Discuter] → Chat du groupe
- [📝 Quiz groupe] → Quiz collaboratif

**📚 Dans Fiches**
- [📝 Quiz depuis fiche] → Générer quiz
- [📤 Partager] → Partager dans groupe
- [💬 Discuter] → Discuter de la fiche

**📝 Dans Quiz**
- [🎥 Session quiz] → Quiz en live
- [📤 Partager] → Partager dans groupe
- [📚 Créer fiche] → Fiche de révision

**🎥 Dans Sessions**
- [💬 Chat] → Ouvrir messages
- [📚 Partager fiche] → Partager ressource
- [✨ Aide IA] → Demander à l'IA

---
