✅ CE QUI A ÉTÉ AJOUTÉ

1. Détection Automatique de l'Appareil
   → Le système détecte si vous êtes sur mobile ou desktop
   → Applique automatiquement la bonne limite

2. Validation AVANT Extraction
   → Les fichiers sont vérifiés AVANT de commencer
   → Évite le crash du navigateur
   → Économise du temps et de la batterie

3. Messages d'Erreur Clairs
   → Indique exactement quel fichier est trop gros
   → Affiche la taille du fichier
   → Donne des conseils pour résoudre

4. Indicateur Visuel
   → Affiche la limite dans l'interface
   → "📱 Mobile : 10 MB max par fichier"
   → "💻 Desktop : 50 MB max par fichier"

💡 SOLUTIONS POUR LES GROS FICHIERS

Problème : Votre fichier fait 20 MB sur mobile

Solution 1 : Compresser le PDF
  → Utilisez iLovePDF.com (gratuit)
  → Réduction de 50-80% de la taille
  → 20 MB → 4-10 MB

Solution 2 : Diviser le Document
  → Utilisez iLovePDF Split (gratuit)
  → 20 MB → 2 fichiers de 10 MB
  → Importez-les séparément

Solution 3 : Utiliser un Ordinateur
  → Ouvrez WordCraft sur un PC/Mac
  → Limite de 50 MB au lieu de 10 MB
  → Les documents seront sauvegardés

Solution 4 : Extraire les Pages Importantes
  → Créez un PDF avec uniquement les pages nécessaires
  → 200 pages → 20 pages
  → Fichier beaucoup plus léger

⚠️ POURQUOI CES LIMITES ?

1. Mémoire Limitée sur Mobile
   Desktop : 4-16 GB RAM disponible
   Mobile  : 1-4 GB RAM disponible
   
   Un fichier de 50 MB peut utiliser 200-300 MB de RAM
   pendant l'extraction.

2. Limite localStorage
   Le navigateur a une limite de ~5-10 MB pour localStorage.
   Si vous dépassez, l'import échoue et le navigateur peut crasher.

3. Performance
   PDF de 10 MB = 2-5 secondes sur mobile
   PDF de 50 MB = 10-30 secondes sur mobile
   Risque de "Page non responsive"

📝 COMMENT VÉRIFIER LA TAILLE DE VOS FICHIERS

Sur Mobile :
  1. Ouvrez l'application Fichiers
  2. Trouvez votre PDF
  3. Appuyez longuement → Informations
  4. Vérifiez la taille

Sur Desktop :
  1. Faites un clic droit sur le fichier
  2. Propriétés (Windows) ou Lire les informations (Mac)
  3. Vérifiez la taille

Dans WordCraft :
  → La taille s'affiche automatiquement dans l'interface
  → "📱 Mobile : 10 MB max par fichier"
