## 🎯 Comment Utiliser ?

### Option 1 : Upload Direct (NOUVEAU !)

#### Pour un QUIZ
```
1. Cliquer "Nouveau quiz"
2. Laisser "IA depuis document" sélectionné
3. Cliquer sur la zone "📤 Choisir un fichier"
4. Sélectionner votre PDF/DOCX
5. Ajuster le curseur (5-20 questions)
   → Défaut : 10 questions
6. Cliquer "Générer depuis document"
```

#### Pour des FICHES
```
1. Cliquer "Nouvelle fiche"
2. Choisir "IA depuis document"
3. Cliquer sur la zone "📤 Choisir un fichier"
4. Sélectionner votre PDF/DOCX
5. Ajuster le curseur (10-30 flashcards)
   → Défaut : 15 flashcards
6. Cliquer "Générer par IA"
```

**Résultat : Quiz/Fiches créés en 30-40 secondes ! ⚡**

---

### Option 2 : Document Existant

Si vous avez déjà uploadé un document dans la Bibliothèque :

```
1. Nouveau quiz/fiche
2. Sélectionner dans la liste déroulante
3. Ajuster le nombre
4. Générer
```

---

### Option 3 : IA sur un Sujet (Quiz seulement)

Pour créer un quiz sur un sujet sans document :

```
1. Nouveau quiz
2. Choisir "IA sur un sujet"
3. Entrer : "BIOLOGIE" ou "Système cardiovasculaire"
4. Ajuster le nombre
5. Générer
```

**L'IA crée d'abord un cours complet puis génère le quiz !**
