✅ L'IA PEUT LIRE ET COMPRENDRE :

📄 DOCUMENTS TEXTUELS
  ✅ PDF       (.pdf)           → Texte complet
  ✅ Word      (.docx, .doc)    → Texte complet
  ✅ PowerPoint (.pptx, .ppt)   → Chaque diapositive
  ✅ Excel     (.xlsx, .xls)    → Toutes les feuilles (NOUVEAU ✨)
  ✅ Texte     (.txt, .md, .csv) → Texte brut

📸 IMAGES (OCR Automatique)
  ✅ Photos    (.jpg, .jpeg, .png, .gif, .bmp, .webp)
     → Extraction automatique du texte (10-30 secondes)
     → Langues : Français + Anglais

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ L'IA NE PEUT PAS LIRE :

🎥 VIDÉOS
  ❌ MP4, AVI, MOV, WEBM, MKV
     → Pas de transcription automatique
     → Solution : Utilisez Otter.ai ou Rev.com pour transcrire,
                  puis importez le texte en .txt

🎵 AUDIO
  ❌ MP3, WAV, OGG, AAC, FLAC
     → Pas de transcription automatique
     → Solution : Utilisez Otter.ai ou Rev.com pour transcrire,
                  puis importez le texte en .txt

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🎯 CE QUE L'IA PEUT FAIRE AVEC VOS FICHIERS :

  1. Lire et comprendre le contenu complet
     → "Résume-moi ce document"
     → "Quels sont les concepts clés ?"

  2. Répondre à des questions précises
     → "Quelle est la définition de X ?"
     → "Explique-moi la section 3"

  3. Analyser plusieurs documents en même temps
     → "Compare ces deux cours"
     → "Quels sont les points communs ?"

  4. Créer du contenu basé sur vos documents
     → "Crée-moi un quiz sur ce cours"
     → "Génère des flashcards"

  5. Extraire des informations structurées
     → "Liste tous les concepts importants"
     → "Résume chaque chapitre en 3 points"

💡 CONSEILS POUR DE MEILLEURS RÉSULTATS

Pour les Images (OCR) :
  ✅ Utilisez des images nettes et bien éclairées
  ✅ Le texte doit être lisible (pas trop petit)
  ✅ Évitez les photos floues ou mal cadrées
  ✅ Préférez les captures d'écran aux photos

Pour les Documents :
  ✅ Les PDF avec texte sélectionnable fonctionnent mieux
  ✅ Pour les PDF scannés, convertissez-les en images
  ✅ Les fichiers Excel sont extraits en format tabulaire

Pour les Vidéos/Audio :
  ❌ Transcrivez d'abord avec :
     • Otter.ai (gratuit, 300 min/mois)
     • Rev.com (payant, très précis)
     • YouTube (sous-titres automatiques)
  ✅ Puis importez le texte transcrit en .txt

🚀 COMMENT UTILISER

1. Ouvrez l'Assistant IA dans WordCraft
2. Cliquez sur "Importer"
3. Sélectionnez vos fichiers (PDF, DOCX, PPTX, XLSX, TXT, Images)
4. Attendez l'extraction (quelques secondes)
5. Posez vos questions à l'IA !

L'IA a maintenant accès au contenu complet de vos fichiers !
