# Guide Utilisateur - Système de Dossiers

## 🎯 Vue d'ensemble

Votre bibliothèque dispose maintenant d'un système complet de dossiers pour organiser vos documents PDF !

## 📁 Fonctionnalités

### 1. Créer un nouveau dossier

1. Cliquez sur le bouton **"Nouveau dossier"** (violet) en haut à droite
2. Saisissez un nom pour votre dossier (ex: "Cours de Biologie")
3. Cliquez sur **"Créer"**
4. Le dossier apparaît immédiatement dans votre bibliothèque

### 2. Uploader un PDF dans un dossier

**Méthode 1 : Upload avec sélection de dossier**
1. Cliquez sur **"Upload PDF"** (bouton rouge)
2. Une modale s'ouvre avec la liste de vos dossiers
3. Sélectionnez un dossier ou laissez "Aucun dossier (Racine)"
4. Cliquez sur **"Sélectionner des fichiers PDF"**
5. Choisissez un ou plusieurs fichiers PDF
6. Les fichiers sont uploadés directement dans le dossier sélectionné

**Méthode 2 : Upload rapide dans le dossier ouvert**
1. Ouvrez un dossier en cliquant dessus
2. Le sélecteur de dossier retiendra votre dernier choix
3. Uploadez directement dans ce contexte

### 3. Naviguer dans vos dossiers

**Vue Racine (par défaut)** :
- 📁 **Dossiers** affichés en haut avec un fond vert/teal
- 📄 **Documents sans dossier** affichés en dessous
- Nombre de documents dans chaque dossier affiché

**Ouvrir un dossier** :
- Cliquez sur une carte de dossier
- Seuls les documents de ce dossier sont affichés
- Un fil d'ariane apparaît : "Tous les dossiers > Nom du dossier"

**Retour à la racine** :
- Cliquez sur **"Tous les dossiers"** dans le fil d'ariane

### 4. Recherche

- La barre de recherche fonctionne avec les noms de dossiers ET de documents
- Tapez un mot-clé pour filtrer instantanément

### 5. Compteurs intelligents

En haut de la page, vous voyez :
```
X dossier(s), Y document(s)
```

Ce compteur reflète les éléments visibles selon votre contexte :
- **À la racine** : Total des dossiers + documents sans dossier
- **Dans un dossier** : 0 dossier + documents du dossier

## 🎨 Interface Visuelle

### Dossiers
- **Apparence** : Carte avec fond dégradé vert/teal
- **Icône** : 📁 Grande icône de dossier
- **Info** : Nom + nombre de documents

### Documents
- **Apparence** : Carte avec fond blanc
- **Icône** : Selon le type (PDF, DOCX, etc.)
- **Info** : Nom original (avec accents) + date de création

## ⚙️ Règles Techniques

### Nom de fichiers
✅ **Nom original conservé** : Vos fichiers PDF gardent leur nom d'origine avec accents et espaces pour l'affichage

✅ **Stockage sûr** : Les fichiers sont stockés avec un nom nettoyé automatiquement pour éviter les erreurs

**Exemple** :
- Nom affiché : `"Virologie Général #1.pdf"`
- Nom stocké : `"1735245678-abc123-virologie-general-1.pdf"`

### Organisation
- Les documents peuvent être **sans dossier** (racine)
- Un document ne peut être que dans **un seul dossier** à la fois
- Supprimer un dossier **conserve** les documents (ils retournent à la racine)

## 🚀 Workflow Recommandé

1. **Créer vos dossiers thématiques** :
   - "Cours 1er semestre"
   - "Examens"
   - "Projets"
   - etc.

2. **Uploader vos documents** en sélectionnant le bon dossier

3. **Naviguer** entre dossiers pour retrouver rapidement vos fichiers

4. **Utiliser la recherche** pour trouver un document spécifique

## 💡 Astuces

- **Organisez par thème** : Un dossier par matière, projet ou période
- **Noms clairs** : Donnez des noms de dossiers explicites
- **Documents sans dossier** : Utilisez la racine pour les documents temporaires ou non classés
- **Recherche globale** : La recherche fonctionne même dans les dossiers
